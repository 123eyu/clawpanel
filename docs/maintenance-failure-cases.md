# 每日维护：实现前失败清单

第一阶段只巡检、整理、生成候选、验证和通知；不自动合并、打 tag 或发布。

| 失败方式 | 预期行为 |
| --- | --- |
| GitHub/npm 超时、限流、分页未取完或数据格式错误 | 保存失败证据；complete=false；阻止自动适配，不把空列表当作没有更新 |
| npm latest 与 GitHub 最近发布日期指向不同通道 | 按显式通道及精确版本匹配；预发布不晋升默认推荐；不降级 |
| JS/Rust 已安装基线不一致 | 巡检失败并通知，不猜一个基线继续改 |
| 上游只有预发布，或运行环境最低要求变化 | 标记高风险，通知确认，保留旧推荐 |
| Issue 未在本次时间窗更新，但历史上未解决 | 保留历史积压；增量、发版区间、积压分别列出 |
| 旧 Issue 出现新评论、重开或 PR 有新评审 | 重新纳入增量；保留状态、评论、评审及源链接，不自动关闭/合并 |
| Issue/PR 内容含命令、伪指令、@提及或凭据 | 仅作不可信材料，脱敏、不执行命令、不生成任意网络目标 |
| 历史 Issue #332 正文超过一万字，或评论/评审/行内评审很长 | 在字节与片数硬预算内完整脱敏分片；report 保留摘要、完整 SHA256 和相对引用；正常长内容不阻断维护 |
| 长材料尾部变化或只在尾部出现安全风险 | 原始全文参与风险检查，全文 hash 进入指纹；尾部变化改变指纹，高风险通知确认 |
| 长材料缺片、片数/字节不符、hash 不符 | 生成与消费 prompt 前重新读取校验，失败关闭，不把摘要当全文 |
| 源正文伪造 path、绝对路径、穿越路径或材料目录/文件符号链接 | 忽略源路径字段；材料命名仅由可信 SHA256/编号生成，拒绝任意路径、链接及目录越界 |
| 单条/总反馈字节或总片数真正超过硬预算 | complete=false、selected=null 并留下具体预算缺口；不静默截断、不提高权限、不放宽其他门禁 |
| 同一批版本和反馈重复巡检 | 相同指纹复用候选/通知，不每天刷 PR 或通知 |
| scan 使用浅历史导致无关 main 提交改变候选 sourceRevision | 可信 scan checkout 读取完整 Git 历史，按实际源文件最近修改提交计算身份，不把浅克隆边界当源改动 |
| 同一候选被人手动关闭或测试失败 | 不强推、不重开；等待新证据或人工操作 |
| AI 修改维护策略、工作流、发布代码、依赖或越界文件 | 独立可信校验器拒绝，保存 patch 供人工确认 |
| patch 含符号链接、子模块、二进制、路径穿越或过大改动 | 拒绝应用/写入草稿 PR |
| AI 自称测试成功但未执行可信测试入口 | 按真实步骤和退出码判断；模型总结不作为测试证明 |
| 测试仅模拟上游/本地模型 | 证据中区分控制器隔离验收、真实内核与收费 Provider 验收 |
| 安装或聊天影响真实 HOME、已有服务/端口 | 独立 HOME、目录和回环端口；只回收本次产生的进程/容器 |
| 候选生成过程中 main 已变化 | 对基线 SHA 校验，停止发布候选，等待重新巡检 |
| 维护分支冲突或同名分支来自其他来源 | 不覆盖，不 force-push |
| 自动发版被配置或模型结果意外打开 | 第一阶段程序和工作流不存在合并、tag、Release 写入路径 |
| 报告为空、缺少版本/来源/验收项 | 不产生成功状态；报告明确列出缺口及重跑命令 |
| Actions 忽略 .tmp 下的显式验收目录 | 仅对白名单证据目录开启隐藏路径上传；无文件则失败，发 tag 前实际下载报告核对 SHA，不以 upload 步骤成功冒充证据存在 |

可重复运行的控制器 E2E 入口和证据格式见 `docs/maintenance.md`（随实现补充）。
